# Contributing Guide

## Branch Strategy
- `main` - Production code.
- `feature/name` - For new functionality.
- `bugfix/name` - For resolving issues.

## Commit Messages
Use conventional commits:
- `feat: Add AI debugger`
- `fix: Resolve layout shift on dashboard`

## Pull Request Process
1. Ensure code lints successfully (`npm run lint`).
2. Do not introduce new architectural patterns without team consensus.
3. PRs require at least one code review approval.
