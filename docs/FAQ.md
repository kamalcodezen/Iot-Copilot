# Frequently Asked Questions

## Developers
**Q: Why use a custom fetch wrapper instead of Axios?**
A: To minimize bundle size and maintain strict, native control over the Request/Response lifecycle across Server Components and Client Components in Next.js.

**Q: Can I add a new database?**
A: All new state must integrate via the `services/` layer in the backend. Consult the architectural committee.

## Users
**Q: What IoT boards are supported?**
A: The AI Mentor can help with any generic board (ESP32, Arduino, Raspberry Pi).
