# User Flow — IoT Copilot AI

## Onboarding Flow
```
Landing Page → Sign Up → Skill Assessment → Personalized Dashboard
```

## Core Learning Flow
```
Dashboard → AI Mentor → Ask Question → Get Answer → Save to Memory → Update Progress
```

## Project Building Flow
```
Dashboard → New Project → AI Project Planner → Get Plan → Build → Mark Complete → Show in Portfolio
```

## Debugging Flow
```
Dashboard → AI Debugger → Describe Problem → AI Asks Clarifying Questions → Step-by-Step Diagnosis → Fix Applied
```

## Roadmap Flow
```
Dashboard → Learning Path → Generate Roadmap → Follow Modules → Complete → Next Roadmap
```

## Interview Practice Flow
```
Dashboard → Interview Coach → Select Difficulty → Get Questions → Answer → Get Feedback → Track Score
```

## Full User Journey
```
Landing → Register → Onboarding Quiz → Dashboard
  → AI Mentor (daily learning)
  → Learning Path (weekly goals)
  → Projects (hands-on building)
  → Debugger (problem solving)
  → Interview Coach (career prep)
  → Community (sharing)
  → Profile (showcasing)
```

## Sidebar Navigation Flow
```
Sidebar (collapsible)
├── Dashboard (default)
├── AI Mentor
├── Learning Path
├── My Projects
├── Explore Projects
├── AI Debugger
├── Interview Coach
├── Community
├── Profile
├── Settings
└── Admin (if admin)
```
